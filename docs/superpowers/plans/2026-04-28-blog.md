## Task 2: 모델 작성

> **흐름 설명:** 모델은 DB 테이블을 PHP 객체로 다루는 클래스입니다.
> `Post::all()` 처럼 쓰면 posts 테이블 전체를 가져옵니다.
> `관계(relationship)` 메서드로 연결된 테이블 데이터를 함께 가져올 수 있습니다.

**Files:**
- Create: `app/Models/Post.php`
- Create: `app/Models/Category.php`

- [ ] **Step 1: Post 모델 작성**

```php
<?php
// app/Models/Post.php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Factories\HasFactory;

class Post extends Model
{
    use HasFactory;

    // DB에 저장 허용할 컬럼 목록
    protected $fillable = [
        'user_id',
        'category_id',
        'title',
        'content',
        'cover_image',
        'visibility',
        'views',
    ];

    // 글 작성자 (users 테이블)
    public function user()
    {
        return $this->belongsTo(User::class);
    }

    // 카테고리 (categories 테이블)
    public function category()
    {
        return $this->belongsTo(Category::class);
    }

    // 태그 목록 (post_tag 연결 테이블을 통해)
    public function tags()
    {
        return $this->belongsToMany(Tag::class);
    }
}
```

## Task 4: 라우트 설정

> **흐름 설명:** 라우트는 "어떤 URL로 들어오면 어떤 컨트롤러를 실행할지" 정의합니다.
> `middleware('auth')` = 로그인하지 않으면 접근 불가.
> `middleware('guest')` = 이미 로그인한 사람은 접근 불가.

**Files:**
- Modify: `routes/web.php`

- [ ] **Step 1: web.php 전체 교체**

```php
<?php

use Illuminate\Support\Facades\Route;
use App\Http\Controllers\AuthController;
use App\Http\Controllers\PostController;
use App\Http\Controllers\CategoryController;
use App\Http\Controllers\TagController;

// ── 메인 피드 (비로그인도 볼 수 있음) ──────────────────────
Route::get('/', [PostController::class, 'index'])->name('home');

// ── 인증 (로그인 안 한 사람만 접근 가능) ───────────────────
Route::middleware('guest')->group(function () {
    Route::get('/login',     [AuthController::class, 'loginForm'])->name('login');
    Route::post('/login',    [AuthController::class, 'login']);
    Route::get('/register',  [AuthController::class, 'registerForm'])->name('register');
    Route::post('/register', [AuthController::class, 'register']);
});

// 로그아웃 (로그인한 사람만)
Route::post('/logout', [AuthController::class, 'logout'])->name('logout')->middleware('auth');

// ── 글 (로그인 필요한 것만 auth 미들웨어) ───────────────────
Route::get('/post/{post}',      [PostController::class, 'show'])->name('posts.show');

// AJAX: 조회수 증가 (비로그인 사용자도 글을 볼 수 있으므로 auth 밖에 위치)
Route::post('/post/{post}/views', [PostController::class, 'incrementViews'])->name('posts.views');

Route::middleware('auth')->group(function () {
    Route::get('/write',              [PostController::class, 'create'])->name('posts.create');
    Route::post('/write',             [PostController::class, 'store'])->name('posts.store');
    Route::get('/post/{post}/edit',   [PostController::class, 'edit'])->name('posts.edit');
    Route::put('/post/{post}',        [PostController::class, 'update'])->name('posts.update');
    Route::delete('/post/{post}',     [PostController::class, 'destroy'])->name('posts.destroy');
    Route::get('/my',                 [PostController::class, 'my'])->name('posts.my');
});

// ── 카테고리 / 태그 목록 ─────────────────────────────────────
Route::get('/category/{slug}', [CategoryController::class, 'show'])->name('categories.show');
Route::get('/tag/{slug}',      [TagController::class, 'show'])->name('tags.show');
```

## Task 5: PostController 작성

> **흐름 설명:** 컨트롤러는 요청을 받아서 처리하고 뷰(화면)에 데이터를 전달하는 역할입니다.
> `index()` = 목록, `create()` = 작성 폼, `store()` = 저장, `show()` = 상세, 등.

**Files:**
- Create: `app/Http/Controllers/PostController.php`

- [ ] **Step 1: PostController 작성**

```php
<?php
// app/Http/Controllers/PostController.php

namespace App\Http\Controllers;

use App\Models\Post;
use App\Models\Tag;
use App\Models\Category;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\Storage;
use Illuminate\Support\Str;

class PostController extends Controller
{
    // ── 공개 피드 (메인 페이지) ────────────────────────────
    // 공개(public) 글만 최신순으로 12개씩 페이지네이션
    public function index()
    {
        $posts = Post::with(['user', 'category', 'tags'])
            ->where('visibility', 'public')
            ->latest()
            ->paginate(12);

        return view('home', compact('posts'));
    }

    // ── 글 작성 폼 ────────────────────────────────────────
    // 로그인한 사용자의 카테고리 목록도 함께 전달 (폼에서 선택)
    public function create()
    {
        $categories = Category::where('user_id', Auth::id())->get();
        return view('posts.create', compact('categories'));
    }

    // ── 글 저장 ───────────────────────────────────────────
    public function store(Request $request)
    {
        // 유효성 검사: 제목과 본문은 필수
        $request->validate([
            'title'       => 'required|max:255',
            'content'     => 'required',
            'visibility'  => 'required|in:public,private',
            'cover_image' => 'nullable|image|max:5120',
        ]);

        // 대표 이미지 업로드 처리
        $coverPath = null;
        if ($request->hasFile('cover_image')) {
            $coverPath = $request->file('cover_image')->store('covers', 'public');
        }

        // posts 테이블에 글 저장
        $post = Post::create([
            'user_id'      => Auth::id(),
            'category_id'  => $request->category_id ?: null,
            'title'        => $request->title,
            'content'      => $request->content,
            'cover_image'  => $coverPath,
            'visibility'   => $request->visibility,
        ]);

        // 태그 처리: "Laravel, PHP, 일상" → 각각 분리 후 저장/연결
        $this->syncTags($post, $request->tags ?? '');

        return redirect()->route('posts.show', $post)->with('success', '글이 등록됐습니다.');
    }

    // ── 글 상세 보기 ──────────────────────────────────────
    public function show(Post $post)
    {
        // 비공개 글은 작성자만 볼 수 있음
        if ($post->visibility === 'private' && $post->user_id !== Auth::id()) {
            abort(403, '비공개 글입니다.');
        }

        return view('posts.show', compact('post'));
    }

    // ── 글 수정 폼 ────────────────────────────────────────
    public function edit(Post $post)
    {
        // 본인 글이 아니면 403 에러
        abort_if($post->user_id !== Auth::id(), 403);

        $categories = Category::where('user_id', Auth::id())->get();
        return view('posts.create', compact('post', 'categories'));
    }

    // ── 글 수정 저장 ──────────────────────────────────────
    public function update(Request $request, Post $post)
    {
        abort_if($post->user_id !== Auth::id(), 403);

        $request->validate([
            'title'       => 'required|max:255',
            'content'     => 'required',
            'visibility'  => 'required|in:public,private',
            'cover_image' => 'nullable|image|max:5120',
        ]);

        $coverPath = $post->cover_image;
        if ($request->hasFile('cover_image')) {
            if ($coverPath) Storage::disk('public')->delete($coverPath);
            $coverPath = $request->file('cover_image')->store('covers', 'public');
        }

        $post->update([
            'category_id' => $request->category_id ?: null,
            'title'       => $request->title,
            'content'     => $request->content,
            'cover_image' => $coverPath,
            'visibility'  => $request->visibility,
        ]);

        $this->syncTags($post, $request->tags ?? '');

        return redirect()->route('posts.show', $post)->with('success', '글이 수정됐습니다.');
    }

    // ── 글 삭제 ───────────────────────────────────────────
    public function destroy(Post $post)
    {
        abort_if($post->user_id !== Auth::id(), 403);

        if ($post->cover_image) {
            Storage::disk('public')->delete($post->cover_image);
        }

        $post->delete();

        return redirect()->route('posts.my')->with('success', '글이 삭제됐습니다.');
    }

    // ── 내 글 목록 ────────────────────────────────────────
    public function my()
    {
        // 공개/비공개 모두 보여주되 최신순
        $posts = Post::with(['category', 'tags'])
            ->where('user_id', Auth::id())
            ->latest()
            ->paginate(20);

        return view('posts.my', compact('posts'));
    }

    // ── AJAX: 조회수 증가 ─────────────────────────────────
    public function incrementViews(Post $post)
    {
        $post->increment('views');
        return response()->json(['views' => $post->views]);
    }

    // ── 태그 동기화 (내부 메서드) ─────────────────────────
    // "Laravel, PHP, 일상" 같은 문자열을 받아서
    // tags 테이블에 없으면 추가하고 post_tag 테이블에 연결
    private function syncTags(Post $post, string $tagString): void
    {
        if (empty(trim($tagString))) {
            $post->tags()->detach(); // 태그 전부 제거
            return;
        }

        $tagIds = [];
        $tagNames = array_filter(array_map('trim', explode(',', $tagString)));

        foreach ($tagNames as $name) {
            $slug = Str::slug($name); // "Laravel PHP" → "laravel-php"
            // 이미 있는 태그면 가져오고, 없으면 새로 만듦
            $tag = Tag::firstOrCreate(
                ['slug' => $slug],
                ['name' => $name, 'slug' => $slug]
            );
            $tagIds[] = $tag->id;
        }

        // post_tag 테이블 동기화 (기존 연결 제거 후 새로 연결)
        $post->tags()->sync($tagIds);
    }
}
```
